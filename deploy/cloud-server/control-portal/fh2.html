FlightHub 2 – Native Components

Offizielle DJI-Frontend-Komponenten werden erst nach Eingabe eines kompatiblen FlightHub-2-Servers geladen. Die lokale AeroNexus-DJI-Cloud-API auf Port 8085 ersetzt diesen Server nicht.

DJI-Originalprojekt ↗
Achtung: Eine native DJI-Komponente kann eigene Bedienelemente einschließlich möglicher Steuerfunktionen bereitstellen. Dies ist kein schreibgeschützter Modus. Nur mit einem vertrauenswürdigen FlightHub-2-Server und bei ausgeschlossener unbeabsichtigter Flugausführung verwenden. Auf Port 8085 läuft ohne ausdrückliche Aktivierung weiterhin ausschließlich die bestehende Pilot-2-Weboberfläche.

Verbindung konfigurieren

Keine Zugangsdaten werden in localStorage, Cookies oder der URL gespeichert. Das Token wird beim Laden an das vertrauenswürdige DJI-SDK im Browser übergeben.

Nur HTTPS oder HTTP auf privaten IPv4-Adressen / localhost. Frontend- und Backend-Host müssen übereinstimmen. Bei Fehlern Seite neu laden. Die URL allein genügt nicht: DJI-Dienst, Freischaltung und Token werden benötigt.
